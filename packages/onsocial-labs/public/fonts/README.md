# Labs font

`inter/inter-latin-wght-normal.woff2` is Inter, latin, normal, wght 100–900.

Bytes: the latin woff2 from `https://fonts.googleapis.com/css2?family=Inter:wght@100..900&display=swap` on 2026-11-13 (Chrome 104 user agent). Upstream: [google/fonts](https://github.com/google/fonts) `ofl/inter` v20. `@fontsource-variable/inter@5.3.0` has the same outlines.
